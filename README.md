## Who I am

I spent five years building and supporting enterprise retail data systems at scale. Most of that time was spent working on Azure, Snowflake, and Databricks platforms for Williams-Sonoma and Macy's, where broken pipelines directly affected fulfillment, reporting, and downstream operations across hundreds of stores.

That environment taught me far more than how to write ETL jobs. It taught me how production systems actually behave under pressure. A lot of the work involved debugging failed loads, investigating data inconsistencies, tuning Spark jobs processing terabytes of data, and helping operational teams stabilize systems during high-pressure release windows.

Over time, I moved deeper into platform engineering and architecture work across ingestion frameworks, Delta Lake pipelines, orchestration systems, Snowflake modeling, and near real-time processing workloads.

During graduate school at Indiana University, my interests shifted further into distributed streaming systems and AI infrastructure. I started building Kafka ingestion systems, experimenting with LLM fine-tuning, and working on evaluation pipelines for domain-specific model workflows.

Most of the projects I work on now sit where data engineering meets AI systems. I enjoy building practical infrastructure where pipelines directly support intelligent applications instead of stopping at dashboards or reporting layers.

## Projects

### [Job AI Matcher](https://github.com/Junaid-Techie/job-ai-app)

I originally built this because I was manually tailoring resumes for every application and wanted a better workflow. The platform uses FastAPI, PostgreSQL, pgvector, and OpenAI embeddings to match resumes against live job descriptions using semantic similarity instead of keyword matching.

Current focus areas:
- Vector similarity search
- Resume parsing
- Semantic ranking
- GPT-assisted interview preparation
- Retrieval workflows

---

### [Sales Prediction Pipeline](https://github.com/Junaid-Techie/sales-prediction-main)

Streaming ingestion and forecasting pipeline built around Kafka, Spark, and Airflow orchestration.

The project focuses on:
- Structured Streaming
- Automated validation
- Batch forecasting
- Workflow orchestration
- End-to-end pipeline automation

### [Python Code Generator](https://github.com/Junaid-Techie/PythonCodeGen-Repo)

Research project from my time in the COMET Lab focused on lightweight LLM fine-tuning for Python code generation.
